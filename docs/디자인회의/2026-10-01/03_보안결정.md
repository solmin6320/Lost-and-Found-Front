# PM 결정 — 보안 담당 제안 (2026-10-01)

본인 지시 : "보안 에이전트가 내놓은 제안 중 **사용자 편의성 측면에서 더 효율적인 걸로**".
PM 판단 기준 : ① 평소에는 **보이지 않고** 필요한 순간에만 나타나는 방식을 고른다 ② 늘 떠 있는 경고는 **줄인다**(경고 피로) ③ 버튼을 옮겨 익숙한 자리를 흔드는 해결보다 **자리는 그대로 두는** 해결 ④ 기존 보안 결정을 뒤집는 것은 2차 토론으로.

| ID | 결정 | 고른 방식과 이유 |
|---|---|---|
| SE-1 두 번 누름 | **채택 — 누름 무시만** | 확인 버튼이 열린 뒤 **0.5초 안의 마우스·터치 누름만** 무시(키보드·[취소]는 즉시). 버튼 모양은 바꾸지 않는다(비활성처럼 보이면 "안 눌리네?"가 된다). 배치 규칙은 **새로 배치할 때의 기준**으로만 문서에 두고, 지금 버튼을 옮기지 않는다 — 옮기면 익숙한 자리가 흔들리고(제이콥) 다른 겹침이 생긴다. 일반 사용자는 차이를 못 느끼고 더블클릭만 걸러진다 |
| SE-2 사진 속 개인정보 | **채택 — 짧게** | 사진 격자 바로 아래 한 줄만 : "신분증 · 카드 번호 · 이름이 보이면 가리고 올려 주세요." 종류가 카드 · 지갑일 때만 진하게. 습득 글용 두 번째 문장("가린 번호는 주인 확인 질문이 돼요")은 사진 칸이 아니라 **쓰는 요령**으로 옮겨 칸 아래를 한 줄로 유지 |
| SE-3 연락처 감지 | **채택 + 상시 문장 줄이기** | 전화번호 · 주민번호 · 카드 번호 모양이 **있을 때만** 그 칸 아래 한 줄(막지 않음, 칸을 벗어날 때 한 번 판정). 대신 **댓글 칸의 상시 개인정보 문장은 뺀다**(감지가 대신함). 설명 칸 상시 문장은 한 줄로 줄여 남긴다(글 쓰는 사람에게는 미리 알리는 편이 낫다). 날짜 · 버스 번호 · 금액 오탐 테스트 필수 |
| SE-4 연락중 전환 안내 | **채택** | 연락중으로 바꾼 **직후 한 번만** 인라인 한 줄(습득 : 주인 확인 질문 / 분실 : 돈 먼저 요청 거절). 판단하는 순간 · 그 자리라 방해가 가장 적다. 목록 · 첫 화면 경고로 넓히지 않는다 |
| SE-5 쓰는 중 로그아웃 | **채택** | 쓰던 글자가 **있을 때만** 확인(기본 포커스 [계속 쓰기]). 글자가 없으면 지금처럼 바로 로그아웃. 사용자의 작업을 지키는 확인이라 편의가 오른다. 보관 안 함 규칙은 그대로 |
| SE-6 글쓴이 표시 · 닉네임 | **채택** | 글쓴이 표시에 아이콘, 닉네임 방향 격리. 보는 사람 부담 0 |
| SE-7 404 주소 표시 | **채택** | 경로만 · 한 줄 · 40자 말줄임. 오타 찾기 목적은 그대로 |
| SE-8 본문 URL | **접기 채택 · 자동 링크는 2차 토론** | 긴 주소를 한 줄로 접는 것(글자 그대로, 누르면 펼침)만 지금 결정. **누르면 열리는 링크는 편의가 크지만** 보안명세서 2장 결정을 뒤집는 일이라, 안전 조건 7개(3장 ⑤)와 함께 2차 토론에서 정한다 |
| SE-9 7일 로그인 유지 안내 | **채택** | 계정 메뉴 [로그아웃] 바로 아래 흐린 한 줄. 로그아웃해야 하는 이유를 버튼 곁에서 한 번. "로그인 유지" 체크박스는 백엔드(세션 쿠키) 뒤로 |
| SE-10 사진 가리기 도구 | **보류(2차)** | 편의는 크지만 비용 L. SE-2 한 줄로 먼저 보고, 필요하면 2차 로드맵에 |
| 3장 편의 제안의 안전 조건 15개 | **기준으로 채택** | 다른 담당의 편의 제안(최근 검색어 · 공유 · 사진 입구 등)이 들어오면 해당 조건을 그대로 붙인다 |
| 2장 힉스 바닥선 | **채택** | 되돌릴 수 없는 두 동작(삭제 · 완료)의 다이얼로그 1회 · 숫자 · 기본 [취소]는 더 줄이지도 늘리지도 않는다 |

다른 담당 질문에 대한 PM 답
- 질문 1(배치로 풀까, 누름 무시로 풀까) → **누름 무시**. [삭제]를 줄 양 끝으로 벌리는 안은 채택하지 않는다(두 번 누름 위험이 커진다). 수정 · 삭제 간격은 시각 담당 안과 함께 2차 토론에서 "간격만 조금(8→12px) + 모양 차이" 수준으로 본다
- 질문 2(경고 피로) → **상시는 줄이고 필요할 때만**. 위 SE-2 · SE-3 결정대로 늘 떠 있는 개인정보 문장은 세 곳 → 두 곳(설명 칸 · 쓰는 요령), 감지형 한 줄이 나머지를 맡는다

구현 : 화면정의서 · 디자인품질기준 · 보안명세서 반영과 함께 **나머지 안건이 결정된 뒤** 한 번에(본인 10/1 "2차 토론은 나중에").
