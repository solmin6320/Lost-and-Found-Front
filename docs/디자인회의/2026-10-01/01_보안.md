## 한 줄 결론

지금 화면은 "편의 때문에 안전을 깎은 곳"이 거의 없다. 대신 **두 번 누르면 되돌릴 수 없는 확인까지 눌리는 자리**가 하나 있고(SE-1),
분실물 서비스에 특유한 **사진 속 개인정보 · 사칭 가로채기**를 막는 안내가 비어 있다(SE-2 · SE-4). 이번 회의에서 나올 편의 제안(자동 링크 · 전화 걸기 · 최근 검색어 · 공유 · 확인 줄이기)은 3장의 조건을 붙이면 대부분 받을 수 있다.

### 이미 안전해서 **지켜야 할 것**(다른 제안이 깨지 않게)

- 확인 다이얼로그는 되돌릴 수 없는 **둘뿐**(글 삭제 · 완료), 결과를 숫자로, 기본 포커스 [취소], 요청 중 닫히지 않음
- 댓글 삭제의 인라인 확인은 [삭제하기]가 **[삭제]와 다른 자리**에 뜬다(390은 둘째 줄, 1440은 줄 끝) — 수정 · 삭제 4px 간격이 오터치를 일으켜도 한 번 더 묻는다
- [사진 전부 삭제]는 저장 전까지 [기존 사진 유지]로 되돌린다 · 목록 카드에 작성자 없음 · 이메일은 계정 메뉴 · 설정(본인 화면)에만
- 헤더 버튼 4px 간격은 **안전 문제가 아니다** — 헤더에 위험 동작이 없다(로그아웃은 메뉴 안, 구분선 아래). 로그아웃을 헤더로 꺼내자는 제안이 나오면 [계정]과 붙이지 않는다
- 본문 · 댓글 · 검색어는 React 글자로만 그린다(`<script>`가 글자로 보이는 것 — `scr03_detail_other-poster`)

## 2. 법칙별 기준 — 편의를 얼마나 줘도 되나

### 피츠 — 되돌릴 수 없는 동작의 거리 · 확인 패턴

| 동작 | 되돌림 | 확인 패턴 | 거리 기준 |
|---|---|---|---|
| 글 삭제 · 완료로 바꾸기 | 불가 | 다이얼로그 1회(지금 그대로) + **SE-1 누름 무시 0.5초** | 여는 버튼과 확인 버튼이 **같은 자리에 겹치지 않는다**. 자주 쓰는 버튼(수정 · 게시중/연락중)과는 8px 이상 + 모양(빨간 글자 · 따로 떨어진 버튼)으로 가른다 |
| 댓글 삭제 | 불가(잃는 게 작다) | 그 자리 두 번 누르기 — 확인 버튼은 **다른 자리**에 | 수정 · 삭제 4px는 인라인 확인이 받쳐 주는 한 괜찮다. 확인 칸을 [삭제] 바로 아래 같은 x로 옮기는 변경은 금지 |
| 사진 전부 삭제 · 한 장 빼기 | 저장 전 가능 | 인라인 결과 고지(지금 그대로) | 제약 없음 — 되돌릴 수 있다 |
| 작성 취소(글자 있음) | 불가 | 다이얼로그(지금 그대로) | 붙은 제출 줄 [작성 취소] 1/3 · [올리기] 2/3 유지. 좌우를 바꾸지 않는다(엄지 자리에 파괴 동작이 오지 않게) |
| 로그아웃 | 가능 | 없음. **단, 쓰던 글자가 있으면 이탈 확인**(SE-5) | 메뉴 맨 아래 · 구분선 아래(지금 그대로) |

- 모서리 · 가장자리 배치는 터치에서 오히려 누르기 어렵다(브리프 피츠 한계) — 위험 버튼을 "손이 안 닿는 구석"에 숨기는 방식으로 안전을 사지 않는다. 거리 + 확인으로 푼다
- 크게 · 가깝게 만드는 제안(버튼 키우기 · 아래 붙이기)이 **위험 버튼에 붙으면** 위 표를 다시 본다

### 힉스 — 확인 단계를 어디까지 줄여도 되나

- **줄여도 된다** : 되돌릴 수 있는 동작의 확인(이미 없음), 쓴 게 없을 때의 작성 취소 확인(이미 없음), 저장 버튼에서 교체 · 삭제를 다시 묻기(이미 없음)
- **줄이면 안 된다(바닥선)** : 되돌릴 수 없는 두 동작의 다이얼로그 1회 · 결과 숫자 · 기본 포커스 [취소]. 이 셋은 결과 고지 규칙(누르기 전에 · 한 번 · 숫자까지)의 최소형이다
- **늘리지도 않는다** : "삭제"를 직접 치게 하기 · 두 번째 확인 · 비밀번호 재입력 — 잃는 것에 비해 과하고, 다이얼로그를 읽지 않고 누르는 법을 가르친다
- **확인을 "되돌리기 알림"으로 바꾸기 금지** — 서버가 삭제 즉시 사진 · 댓글까지 지운다(되살리는 엔드포인트 없음). 요청을 몇 초 늦춰 보내는 흉내는 탭을 닫으면 **안 지워졌는데 지웠다고 믿는** 더 나쁜 상태를 만든다(4장 하지 말 것 ①)

## 3. 편의 제안이 나오면 붙일 안전 조건

제안이 나오면 해당 줄을 그대로 조건으로 붙인다. 새 저장소 키는 **보안명세서 3장 표부터** 고친다.

1. **최근 검색어(기기 저장)** — `sessionStorage`(탭을 닫으면 사라짐)만. 비로그인도 공용 기기를 쓰므로 "로그아웃 때 지우기"로는 부족하다. 최대 5개 · 한 개 50자 · 칸 옆 [지우기] 늘 보임 · 읽을 때 모양 검사 · 로그아웃하면 지움. 검색어는 이미 주소(`?keyword=`)에 있으니 기록 목록은 글자로만 그린다
2. **최근 본 글** — **글 id만** 저장(제목 · 사진 주소 · 닉네임 저장 금지 — 글이 지워져도 기기에 제목이 남는다). `sessionStorage` · 최대 10개 · 불러와서 없는 글은 조용히 뺀다 · 로그아웃하면 지움
3. **로그인 유지** — 프론트 단독 구현 금지(토큰은 메모리뿐, 3장). 백엔드가 "유지 안 함 = 세션 쿠키"를 줄 때만 체크박스. 기본값은 **꺼짐**(공용 기기 쪽으로 기운다)
4. **공유 버튼 · 주소 복사** — 공유 주소는 `origin + /posts/{id}`로 **새로 만든다**(지금 주소창 복사 금지 — 검색어 · 필터 · 기록 상태가 섞인다). 기기 공유 창이 없으면 클립보드 + `"주소를 복사했어요."` 한 줄. 외부 공유 스크립트 금지(외부 출처 0건 · CSP `script-src 'self'` 유지)
5. **본문 · 댓글 URL 자동 링크** — ① 정규화한 뒤(`new URL`) `http:` · `https:`만, 계정 정보(`user:pass@`)가 든 주소는 링크 안 함(F1 교훈 — 원문 문자열 검사 금지) ② 보이는 글자 = 실제 주소(글자와 다른 곳으로 가는 링크 금지) ③ 링크 옆에 **호스트를 따로** 보여 줌, 퓨니코드(`xn--`) 호스트는 링크로 만들지 않음(닮은 글자 도메인) ④ `target="_blank" rel="noopener noreferrer nofollow ugc"` ⑤ "우리 서비스 밖 주소" 표시 ⑥ 끝 구두점 · 괄호 처리 ⑦ 단위 테스트(`javascript:` · `data:` · 대소문자 · 공백 · 제어 문자 · `//evil` · `https:evil` · 닮은 글자 도메인)
6. **전화번호 탭하면 전화(`tel:`)** — 사용자 글에는 만들지 않는다. 가짜 "보관소 · 고객센터" 번호에 우리 서비스의 권위를 빌려준다. 대신 쓰는 칸에서 알린다(SE-3)
7. **쓰던 글 자동 저장** — 지금 규칙 그대로 : `sessionStorage` · 같은 회원에게만 · 6시간 · 직접 로그아웃하면 지움 · 사진은 저장 안 함. `localStorage`로 넓히지 않는다
8. **이메일 기억하기(로그인 화면)** — 저장소에 넣지 않는다. 브라우저 자동완성(`autocomplete="email"`)이 같은 일을 이미 한다
9. **사진 입구 늘리기(붙여넣기 · 카메라 바로 찍기 · 끌어 놓기)** — 모든 입구가 **같은 검사**를 탄다 : 매직 바이트 · 크기 · 개수 · 위치 정보 제거 · 이름 다듬기(`addFiles` 한 곳)
10. **장소 자동 채우기(현재 위치)** — 하지 않는다. `Permissions-Policy: geolocation=()`를 열어야 하고, 좌표가 공개 글에 남는다. 사람이 적는 장소 이름만
11. **확인 줄이기** — 2장 힉스의 바닥선 셋을 지킨다
12. **위험 버튼 옮기기 · 키우기** — 옮긴 뒤 **확인 버튼과 여는 버튼의 자리 겹침을 390 · 1440에서 잰다**(SE-1). 겹치면 배치를 바꾸거나 누름 무시를 확인한다
13. **강조 · 배지 추가** — 시스템 전용 모양(아이콘 + 면, 완료 도장, 글쓴이 표시)은 **글자 · 이모지로 흉내 낼 수 없어야** 한다. 시스템 문장은 글자만으로 만들지 않는다(면 · 아이콘 · 고정 자리 중 둘 이상). `※` · `!` · `[공지]`처럼 사용자가 칠 수 있는 모양을 시스템 표시로 쓰지 않는다
14. **사용자 입력을 문장 속에 넣기**("'자전거'에 맞는 글이 없어요" · "'검은 지갑' 글을 삭제할까요?") — 따옴표로 감싸고 20자에서 자르고 한 줄. 짧은 알림(Flash) · 다이얼로그 제목 · 안내 면에는 **남의 입력**(제목 · 닉네임 · 댓글)을 넣지 않는다 — 그 면은 시스템의 목소리다
15. **사용자가 켜는 강조(급해요 · 사례금 있음 · 끌어올리기)** — 만들지 않는다. 백엔드 필드도 없고, 모두가 켜면 신호가 사라지며, "사례금" 표시는 가짜 습득자를 부른다

## 4. 하지 말아야 할 것

1. **되돌릴 수 없는 동작의 확인을 없애고 "되돌리기 알림"이나 "늦춰 보내기"로 대신하기** — 서버에 되살리기가 없다. 늦춰 보내다 탭이 닫히면 개인정보가 든 글이 남아 있는데 지웠다고 믿는다
2. **사용자 글 속 전화번호 · 주소를 한 번 눌러 전화 · 이동되게 바꾸기**(조건 없는 자동 링크 · `tel:`) — 피싱 번호 · 주소에 서비스의 신뢰를 얹는다
3. **편의를 위해 로그인 · 개인 흔적을 기기에 오래 남기기** — 토큰 · 이메일 · 검색어 · 본 글 제목을 `localStorage`에. 공용 기기의 다음 사람이 본다
4. **사용자 입력을 시스템의 목소리 자리에 넣거나, 시스템 표시를 글자로 흉내 낼 수 있게 두기** — 알림 · 다이얼로그 제목에 남의 제목 · 닉네임, 글자만으로 된 "공지" · "안내" 표시, 흐린 선 하나뿐인 글쓴이 표시
5. **보안 경고를 곳곳에 되풀이하기** — 첫 화면 · 목록 · 제출 확인창마다 "사기 조심"을 띄우면 아무도 읽지 않는다. 경고는 **판단하는 순간 · 그 대상 옆에 한 번**(사진 격자 아래 · 연락중으로 바꾼 직후 · 쓰는 칸 아래)
