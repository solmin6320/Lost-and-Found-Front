# features — 도메인 단위

백엔드 도메인과 이름을 맞춘다. 게시글 하나를 고칠 때 열어야 할 폴더가 하나가 되도록,
같은 도메인의 API·상태·화면조각을 한곳에 둔다.

| 폴더 | 대응 |
|---|---|
| `auth` | [3.1]~[3.5] 회원가입·로그인·재발급·로그아웃 |
| `posts` | [4.1]~[4.6] 게시글 |
| `comments` | [5.1] 댓글 |
| `members` | [3.6] [3.7] [6.1] 내 정보·마이페이지 |
| `notifications` | 7.6 ① 알림 센터 — 헤더 종 · 펼침 칸 · 실시간 연결(SSE) |
| `matches` | 7.6 ② 자동 매칭 — 내 글 상세의 추천 후보 · 숨기기(SCR-11) |

각 도메인 안의 규칙

```
features/posts/
  api/     서버 호출과 요청·응답 타입
  model/   훅, 상태, 도메인 규칙(상태 전이 등)
  ui/      이 도메인에서만 쓰는 컴포넌트 (PostCard, TypeBadge …)
  index.ts 바깥에 공개할 것만 다시 내보낸다
```

바깥에서는 `features/posts/index.ts` 만 import 한다. 내부 파일을 직접 가져다 쓰기
시작하면 폴더 경계가 의미를 잃는다.
